# 新手一步步来（零命令行）

目标：手机上打开一个网址，每天/每 15 分钟看到自动更新的榜单。**你的电脑关着也能看。**

全程只需要：一个浏览器、一个 GitHub 账号。不需要安装任何软件，不需要敲命令。

---

## 准备工作

- GitHub 账号（没有就注册：https://github.com/signup ，免费）
- 你的 Tushare Token（https://tushare.pro/user/token ，登录后复制那串 40 位的）
- 桌面上那个 **`cn-stock-screener-src.zip`**（195 KB，只有代码，不含 1GB 数据）

---

## 第 1 步：建仓库（2 分钟）

1. 打开 https://github.com/new
2. **Repository name** 填：`stock`（或任何你喜欢的名字）
3. 选 **Public**（公开 —— 免费版 Pages 只支持公开仓库）
4. **不要**勾 "Add a README file"
5. 点绿色 **Create repository**

---

## 第 2 步：把代码传上去（3 分钟）

1. 先在电脑上**解压** `cn-stock-screener-src.zip`，得到 `cn-stock-screener` 文件夹
2. 回到刚建好的仓库页面，点中间的 **uploading an existing file** 链接
3. 打开解压出来的 `cn-stock-screener` 文件夹，**全选里面的所有文件/文件夹**，
   直接拖到浏览器页面上
4. 等进度条走完（约 50 个文件，几秒钟）
5. 页面下方 Commit changes 框里填 `init`，点绿色 **Commit changes**

> 如果拖拽不成功（有些浏览器不支持拖文件夹），改用：
> 点 **Add file → Upload files → choose your files**，同样的方式选。

---

## 第 3 步：加 Token（1 分钟）

**不要把 Token 写进代码，也不要写进任何文件。** 用 Secret：

1. 仓库页面 → 上方 **Settings**
2. 左侧 **Secrets and variables → Actions**
3. 点 **New repository secret**
4. Name 填：`TUSHARE_TOKEN`
5. Secret 填：你的 Token（40 位那串）
6. 点 **Add secret**

---

## 第 4 步：打开网页托管（1 分钟）

1. 还在 **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，右边的目录选 **`/docs`**
4. 点 **Save**

> 这时会提示 "Your site is ready to be published"。
> 你的网址是：`https://你的用户名.github.io/stock/`

---

## 第 5 步：放上定时任务文件（2 分钟）

1. 仓库首页 → **Add file → Create new file**
2. 文件名那里输入：`.github/workflows/stock.yml`
   （输入 `/` 会自动建文件夹，照着一层层打）
3. 打开电脑上的 `cn-stock-screener/deploy/github-actions.yml`，
   **全选复制**，粘贴到网页编辑框里
4. 页面下方点 **Commit changes**

---

## 第 6 步：跑第一次（等 10 分钟）

1. 仓库页面 → 上方 **Actions** 标签
2. 如果提示要启用，点 **I understand my workflows, go ahead and enable them**
3. 左侧点 **cn-stock-screener**
4. 右边点 **Run workflow** → 绿色按钮 **Run workflow**
5. 刷新页面，会看到一条黄点（运行中）→ 变成绿勾（成功）

第一次要拉 750 天历史，**大约 5~10 分钟**，别关页面，等它变绿。

6. 绿勾之后，等 1~2 分钟 Pages 部署，然后手机打开：
   `https://你的用户名.github.io/stock/`

---

## 第 7 步：让它准时自动跑（可选但推荐）

GitHub 自带的定时会漂移 5~15 分钟。要准点，需要一个外部服务来"敲一下"。

### 7.1 先拿一把"只能触发"的钥匙

1. 打开 https://github.com/settings/personal-access-tokens/new
2. **Token name**：`trigger`
3. **Expiration**：90 days
4. **Repository access** → Only select repositories → 选你的 `stock`
5. **Repository permissions** → 只把 **Actions** 改成 **Read and write**，别的都不动
6. 点最下面 **Generate token**，立刻复制（`github_pat_` 开头，只显示一次）

### 7.2 注册定时服务

1. 打开 https://cron-job.org/en/ ，点 Sign up 注册（免费，邮箱验证）
2. 登录后点 **Create cronjob**
3. 按下面填：

| 字段 | 填什么 |
| --- | --- |
| Title | `stock scan` |
| URL | `https://api.github.com/repos/你的用户名/stock/actions/workflows/stock.yml/dispatches` |
| Enable job | 勾上 |
| Schedule | Every 15 minutes，时区 Asia/Shanghai |
| Execution → Request method | **POST** |
| Request body | `{"ref":"main","inputs":{"mode":"scan"}}` |

4. 展开 **Headers**，加三条（一行一条，注意冒号后面有空格）：

```
Accept: application/vnd.github+json
Authorization: Bearer github_pat_你复制的那串
Content-Type: application/json
```

5. **不用 curl，直接点页面下方的 `TEST RUN` 按钮**
6. 看返回：显示 **204** 就是成功；看 GitHub 的 Actions 页面，应该马上多出一条运行

> 204 = 成功但没内容。这是正常的，说明"命令已收到"。

7. 回到 cron-job.org，在 **Advanced** 里限制时段：
   勾选 "Execute only between" → `09:45` ~ `15:00`，星期勾周一到周五
8. 保存

---

## 第 8 步：晚上那次（收盘选股）

白天那个任务只抓行情（`mode=scan`），**不生成新榜单**。
每天收盘后要再跑一次 `mode=rank`，才有第二天的榜单。

在 cron-job.org 再建一个任务：

| 字段 | 填什么 |
| --- | --- |
| Title | `stock nightly` |
| URL | 同上面那个 |
| Schedule | Daily at `22:30`，Asia/Shanghai，周一到周五 |
| Method | POST |
| Body | `{"ref":"main","inputs":{"mode":"rank"}}` |
| Headers | 同上三条 |

## 常见问题

**Q：Actions 页面一直是黄的（运行中）？**
第一次要下载 750 天历史，5~10 分钟正常。超过 20 分钟才可能是出错，点进去看红色那一步的日志。

**Q：红了，报 `TUSHARE_TOKEN` 相关错误？**
第 3 步的 Secret 名字必须**完全**是 `TUSHARE_TOKEN`，大小写也要一样。

**Q：手机打开 404？**
Pages 部署有延迟，等 2 分钟。还不行就看 Settings → Pages 里显示的网址是不是和你打开的一致（注意结尾有没有 `/stock/`）。

**Q：页面一直是旧的？**
`mode=scan` 只更新盘中榜，日线榜要等晚上 `mode=rank`。

**Q：不想公开代码？**
那就得用云服务器方案（见 `README.md` 方案 A），或者私有仓库 + GitHub Pro（$4/月）。

**Q：Token 过期（90 天）后怎么办？**
重新做 7.1，把新的那串替换到 cron-job.org 的 Header 里。

**Q：一个月会不会花很多 Actions 分钟？**
公开仓库免费不限时长。你这个项目每交易日约 17 次 × 3 分钟 ≈ 50 分钟/天，公开仓库不扣费。
